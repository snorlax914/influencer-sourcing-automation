# 릴스 조회수 추출

대시보드(`instacrawl/webapp.py`)는 요청 큐만 들고 있다. 실제 추출은 이 스킬이
Claude for Chrome으로 사용자의 크롬(이미 인스타에 로그인된 세션)을 열어서 한다.

API 기본 주소는 `http://127.0.0.1:8000` (서버를 다른 포트로 띄웠으면 그 포트).

## 절차

### 1. 할 일 가져오기

```bash
curl -s http://127.0.0.1:8000/api/reels/queue
```

`pending`이 비어 있으면 "대기 중인 요청이 없습니다"라고 알리고 끝낸다.
서버가 안 떠 있으면(연결 거부) `uv run python webapp.py`로 먼저 띄우라고 안내한다.

### 2. 시작 표시

처리할 계정들을 claim해서 대시보드에 "추출 중…"으로 보이게 한다.

```bash
curl -s -X POST http://127.0.0.1:8000/api/reels/claim \
  -H "Content-Type: application/json" \
  -d '{"usernames":["acc1","acc2"]}'
```

### 3. 크롬 툴 로드 (한 번만, 한 호출로)

ToolSearch: `select:mcp__claude-in-chrome__tabs_context_mcp,mcp__claude-in-chrome__tabs_create_mcp,mcp__claude-in-chrome__navigate,mcp__claude-in-chrome__get_page_text,mcp__claude-in-chrome__read_page,mcp__claude-in-chrome__computer,mcp__claude-in-chrome__find`

(`find`는 고정 릴스 확인에 반드시 필요하다 — 빠뜨리면 4단계에서 다시 로드하느라
왕복이 한 번 더 든다.)

`tabs_context_mcp`로 현재 탭 상황을 먼저 확인하고, 작업용 탭을 **하나만**
새로 만들어 계정마다 `navigate`로 재사용한다(계정마다 탭을 새로 열지 않는다).

### 4. 계정마다 조회수 읽기

큐 항목의 `reels_url`(= `https://www.instagram.com/<계정>/reels/`)로 이동한다.
계정은 **한 번에 하나씩, 순차로** 처리한다. 여러 탭을 동시에 열어 빠르게
훑으면 인스타가 자동화로 보고 계정을 잠글 수 있다.

페이지가 뜨면 `get_page_text`로 텍스트를 읽는다. 릴스 타일마다 재생 아이콘
옆에 조회수가 붙어 있고, 화면에 보이는 그대로의 축약 표기다.

- 한국어 UI: `1.2만`, `3,456`, `12.3천`
- 영어 UI: `12.3K`, `1.2M`

**단위를 직접 계산하지 말고 읽은 문자열을 그대로 넘긴다.** 서버의
`parse_view_count`가 정수로 바꾼다. 이미 숫자면 숫자로 넘겨도 된다.

순서는 화면에 보이는 순서(최신순)를 유지한다.

**표본은 항상 '고정 제외 최신 12개'로 맞춘다.** 계정마다 표본 수가 다르면
중앙값을 계정끼리 비교할 수 없다 — 9개 vs 12개 차이가 계정 차이로 오인된다.
릴스 그리드는 스크롤한 만큼만 로딩되므로, 스크롤을 3~4틱만 하면 12개를 못 채우고
"그 계정은 릴스가 적다"고 착각하게 된다. **한 번에 8틱 정도 스크롤**해서
`get_page_text`에 숫자가 15개(고정 3 + 일반 12) 이상 잡히는지 확인하고 자른다.

계정 전체 릴스가 12개보다 적으면 있는 만큼만 넣고, `note`에 그 사실을 적는다
(예: `"계정 전체 릴스가 1개 — 12개 기준 미달"`). 표본이 적다는 건 화면에서
보여야 할 정보다. **릴스가 3개 미만이면 스코어링의 도달 축이 아예 빠진다**
(judge.py `MIN_REELS_SAMPLE`) — 1~2개의 중앙값은 평소 성과가 아니라 그날의
운에 가까워서다. 그 계정 점수는 조회수 없는 계정과 같은 방식으로 매겨진다.

**고정(📌) 릴스를 반드시 구분한다.** 맨 앞 타일들에 압정 아이콘이 붙은 것이
고정 릴스다. 계정이 골라 박아둔 대표작이라 평소 성과가 아니고, 보통 평소의
10배씩 나와서 몇 개만 섞여도 중앙값이 자릿수째 달라진다. 고정된 것은 `views`가
아니라 `pinned`에 넣는다(서버가 통계에서 제외하고 참고용으로만 보관한다).

고정 개수는 **`find`로 확인한다** — 질의: `고정된 릴스를 나타내는 압정(pin) 아이콘`.
접근성 라벨이 `고정 게시물`이라 정확히 잡히고, 몇 번째 타일인지도 알려준다.
`get_page_text`에는 안 나오고, **스크린샷도 믿을 수 없다** — 압정이 흰색이라
밝은 배경/자막에 묻혀 안 보이는 경우가 실제로 있었다. 고정은 최대 3개이고 항상
맨 앞에 연속으로 온다.

**`find`는 반드시 스크롤 뒤에 부른다.** 계정마다 `navigate` → `scroll` → `find`
→ `get_page_text` 순서를 지킨다. 이동 직후에는 그리드가 아직 렌더링되지 않아
접근성 트리가 비어 있고, `find`가 "압정 아이콘이 없다"고 **틀린 답을 확신 있게**
돌려준다. 실제로 그렇게 답한 계정의 스크린샷에는 압정이 3개 뚜렷이 보였다.
그대로 믿었으면 고정 3개(7.3만·7.3만·15만)가 일반 표본에 섞여 중앙값이 부풀려졌을
것이다. `find`가 "없음"이라고 했는데 스크린샷에 압정이 보이면 **스크린샷이 맞다**
(위의 '스크린샷도 믿을 수 없다'는 압정이 **보일 때** 세는 걸 믿지 말라는 뜻이지,
보이는 압정을 무시하라는 뜻이 아니다). 다시 스크롤하고 `find`를 한 번 더 부른다.

읽어낸 값이 조회수인지 헷갈리면(좋아요·댓글 수와 섞임) `read_page`로 구조를
확인한다. 릴스 그리드 타일의 오버레이 숫자가 조회수다.

### 5. 결과 저장

계정 하나를 끝낼 때마다 바로 POST한다(중간에 끊겨도 앞선 결과가 남도록).

```bash
curl -s -X POST http://127.0.0.1:8000/api/reels/result \
  -H "Content-Type: application/json" \
  -d '{"username":"acc1","views":["1.2만","8,432","15.3K"],"pinned":["72만"],"note":""}'
```

한글이 들어간 본문(note·error)은 Windows 셸에서 curl `-d`로 바로 넘기면 인코딩이
깨져 400이 난다. **본문을 UTF-8 파일로 쓴 뒤 `--data-binary @파일`로 보낸다.**

- 릴스 탭은 열렸는데 릴스가 하나도 없으면: `views: []`, `note: "릴스 없음"`
- 조회수가 안 뜨는 계정이면: `views: []`, `note: "조회수 비공개"`
- `views`가 비었는데 `note`도 비면 서버가 400을 낸다 — 이유를 반드시 적는다.

실패했을 때(비공개 계정, 로그인 필요, 페이지 로드 실패 등):

```bash
curl -s -X POST http://127.0.0.1:8000/api/reels/fail \
  -H "Content-Type: application/json" \
  -d '{"username":"acc1","error":"비공개 계정 — 팔로우 필요"}'
```

### 6. 마무리

처리한 계정 수와 각 계정의 중앙값을 한 줄씩 요약해 보고한다.
결과는 `instacrawl/reels.csv`에 저장되고 대시보드 표에 자동으로 뜬다
(대시보드는 3초마다 폴링하므로 새로고침 불필요).

조회수는 스코어링의 **도달 축** 재료이기도 하다. 서버가 결과를 저장하면서
그 계정을 자동으로 재채점하므로(LLM 호출 없음), 점수·등급이 같이 바뀔 수 있다.
요약에 등급이 달라진 계정이 있으면 그 사실도 한 줄 덧붙인다.

## 하지 말 것

- 인스타 로그인·비밀번호 입력을 시도하지 않는다. 사용자가 이미 로그인한
  세션을 쓰는 것이 전제이고, 로그인 화면이 뜨면 실패로 기록하고 사용자에게 알린다.
- 확인 대화상자(alert/confirm)를 띄울 수 있는 요소를 클릭하지 않는다.
- 같은 계정에서 2~3번 시도해도 조회수를 못 읽으면 그 계정은 `fail`로 남기고
  다음으로 넘어간다. 같은 페이지를 반복해서 재시도하지 않는다.
